    Vì sao cần proxy? Cách tạo proxy riêng
    Trình duyệt chặn trang web đọc dữ liệu từ site khác (CORS), nên cần một máy chủ trung gian. Proxy công khai có thể chậm, bị giới hạn hoặc ngừng hoạt động. Ổn định nhất là tạo Cloudflare Worker miễn phí với đoạn mã sau, rồi dán địa chỉ vào ô “Proxy của tôi”:
    
export default{async fetch(r){
const u=new URL(r.url).searchParams.get('url');
const x=await fetch(u,{headers:{'User-Agent':'Mozilla/5.0'}});
const h=new Headers(x.headers);
h.set('Access-Control-Allow-Origin','*');
return new Response(x.body,{status:x.status,headers:h})}}
